# My Ecommerce Project

A modern ecommerce application built using Next.js, TypeScript, and Tailwind CSS.

## Features

- Product listing
- Category-based product filtering
- Shopping cart
- Add and remove products
- Responsive design
- Reusable components

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Zustand (State Management)

## Installation

1. Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

2. Navigate to the project:

```bash
cd my-project
```

3. Install dependencies:

```bash
npm install
```

4. Start development server:

```bash
npm run dev
```

5. Open in browser:

```text
http://localhost:3000
```
