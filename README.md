# eShop Project

A modern ecommerce application built using Next.js, TypeScript, Zustand, and Tailwind CSS.

## 🚀 Live Demo

[Click here to view the live project](https://e-commerce-next-js-q2os.vercel.app/)

## Features

- Product listing
- Category based product filtering
- Shopping cart
- Add and remove products
- Responsive design
- Reusable components
- Live Product Viewers
- 
## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Zustand (State Management)
- Socket.IO

## Installation

1. Clone the repository:

```bash
git clone https://github.com/jilsonjoy98/E-commerce-Next-js.git
```

2. Navigate to the project:

```bash
cd e-com
```

3. Install dependencies:

```bash
npm install
```

4. Start development server:

```bash
npm run dev
```

5. Open in browser:

```text
http://localhost:3000
```
